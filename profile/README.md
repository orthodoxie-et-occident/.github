## Fonctionnement

Cette organisation est **francophone** : la documentation et les échanges se font en **français**,
tandis que le **code est écrit en anglais**.

| Élément | Langue |
|---|---|
| Documentation (README, guides, wiki) | 🇫🇷 Français |
| Issues, Pull Requests, Discussions | 🇫🇷 Français ou 🇬🇧 Anglais |
| Revues de code et commentaires de PR | 🇫🇷 Français ou 🇬🇧 Anglais |
| Noms de variables, fonctions, classes, fichiers | 🇬🇧 Anglais |
| Commentaires et docstrings dans le code | 🇬🇧 Anglais |
| Messages de commit | 🇬🇧 Anglais |
| Noms de branches | 🇬🇧 Anglais (`feat/…`, `fix/…`) |
| Messages de log et d'erreur techniques | 🇬🇧 Anglais |
| Textes affichés aux utilisateurs | 🇫🇷 Français |
